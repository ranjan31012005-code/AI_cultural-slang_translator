# AI Cultural & Slang Translator

## About

AI Cultural & Slang Translator is a context-based translation system designed to reduce misunderstandings in global communication.

It analyzes:

- 🌍 Language
- 💬 Slang
- 😊 Tone
- 🧠 Cultural Context

### Supported Languages

- English
- Tamil
- Japanese

### Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON
- NLP

### Features

- Language detection
- Slang detection
- Cultural meaning
- Tone analysis
- Context-aware explanations
